## How to use a skill

Open its directory, read its README and CURATION notes, and download its ZIP. Extract the complete skill folder into the directory supported by your assistant. Review any executable code before running it. Instructions and examples do not establish measured business outcomes.

## Scores and evidence

TRACE content reviews use the pinned skill-trace-checker rubric. A rubric review is distinct from runtime testing and certification. Original rubric limitations are recorded per issue. Fictional demonstrations and scenario estimates are labeled; they are not customer results.
